## Writing new games or a second pass

Every slot is live. Follow `curriculum.ts` for the order, and reuse what exists:

- `MatrixView` for any 2x2 table. `Glyph` for the visual grammar.
- The reveal pattern: Feel collects evidence with a counterfactual, See is built from the player's own moves and needs a tap or drag, Prove changes the numbers.
- `Timeline` in Matching Pennies is a good base for any repeated game that needs a long history.
- `PayoffTable` (in `src/games/shared`) holds a two by two table of [you, them] cells with best replies and stable cells. `drawPayoffCell` and `drawMatrixLabels` in `kit.ts` draw it, and Chicken and Battle of the Sexes show both in use. `Bimatrix` and `GridView` cover tables of any size.
- `drawChoice` and `drawTicks` in `src/games/shared/kit.ts` cover the two box action row and the tick row. `kit.ts` also has its own small `Slider`, next to the `Slider` in `Slider.ts`.
- `Plot` (`src/games/shared/Plot.ts`) for any curve with axes, ticks and a draggable probe.
- The Stag Hunt and Ultimatum chart code is a good base for any "find the crossing or the peak" idea.

Follow `docs/ADDING_A_GAME.md`. Keep the model pure and tested, draw inside the frame (`docs/LAYOUT.md`) and add the game to `tools/verify-layout.mjs`.

## Reusable pieces for new games

- `Game.zonesActive()` and `onZone(i)`: tap zones for choice boxes, table cells, map corners and points. `cells(n, i)` splits the action row, `ticks()` draws progress dots.
- `PayoffPlane`: the you/they plane used by Zero-Sum, Positive-Sum, Negative-Sum and Pareto. `Track`: a draggable ruler.
- The base class re-runs `layout()` whenever `actionH` changes, so a beat can swap choice boxes for a button safely.
- Games 006 to 015 were audited game by game as they were written. Re-run `npm run verify:layout` and `npm run verify:iphone` after pulling.
